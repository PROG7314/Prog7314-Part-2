# Store listing — checklist

What the POE brief needs here, and the status of each piece. Drafted text content is in this folder; images
still need to be produced from the actual running app and dropped in.

| Item | Status | Notes |
|---|---|---|
| App name (≤30 chars) | Done | See `listing-copy.md` |
| Short description (≤80 chars) | Done | See `listing-copy.md` |
| Full description (≤4,000 chars) | Done | See `listing-copy.md` |
| Privacy policy | Drafted | See `privacy-policy.md` — host it as a GitHub Pages page and link the URL from the main README once live |
| Content rating & data safety answers | Drafted | See `content-rating-and-data-safety.md` — review for accuracy before submitting |
| 512×512 PNG launcher icon | **TODO** | Export from Android Studio's Image Asset Studio; drop into `icon/` |
| 1024×500 feature graphic | **TODO** | Needs an actual design; drop into `feature-graphic/` |
| 4+ real screenshots | **TODO** | Take from the signed release build on a physical phone, real data, no placeholders; drop into `screenshots/` |

## Why the images aren't here yet

Icon, feature graphic and screenshots all have to come from the actual built/running app (Image Asset Studio output,
a real design pass, and phone screenshots respectively) — none of that can be produced without running the app, so
these three are left as empty folders for whoever does the Play Store packaging to fill in.
